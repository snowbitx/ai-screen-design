# 主题配色与科技风

## 大屏科技风的配色套路

- 底色：`#0d121b`、`#0b1220`、`rgba(9,14,24,0.9)`，不要纯黑。
- 主色：青色 `#22d3ee`、蓝紫 `#6366f1`、紫 `#a78bfa`。
- 强调色：`#f472b6`（粉）、`#facc15`（金），只用于关键指标。
- 辅助灰：文字 `rgba(255,255,255,0.65)`，次要 `rgba(255,255,255,0.35)`，分割线 `rgba(255,255,255,0.08)`。

## color 调色盘

```js
color: ['#22d3ee', '#6366f1', '#a78bfa', '#f472b6', '#facc15']
```

系列按顺序取色，同一图表里超过 5 个系列时复用前几个色，建议增加透明度区分。

## 发光与渐变

柱子/折线加发光用 `shadowBlur`：

```js
itemStyle: {
  color: { type: 'linear', x: 0, y: 0, x2: 0, y2: 1,
    colorStops: [
      { offset: 0, color: '#22d3ee' },
      { offset: 1, color: 'rgba(34,211,238,0.25)' }
    ] },
  shadowBlur: 12,
  shadowColor: 'rgba(34,211,238,0.45)'
}
```

`shadowBlur` 超过 20 在低端设备上会明显掉帧，大屏轮询刷新时建议 ≤ 12。

## 背景装饰

- 用 `grid.splitLine.lineStyle.type: 'dashed'` + 低透明度做科技感网格。
- 卡片式容器用半透明背景 + 1px 亮边：`background: rgba(255,255,255,0.03)`、`border: 1px solid rgba(255,255,255,0.08)`。

## 常见错误

- 全图统一一个高饱和色，没有主次。
- 发光叠加在面积图上，颜色糊成一片。
